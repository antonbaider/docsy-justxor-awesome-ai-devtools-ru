# Как добавить инструмент

Спасибо за вклад! Список живёт благодаря сообществу.

## Правила

1. **Инструмент — для разработчиков** и использует ИИ как ключевую функцию.
2. **Он работает и доступен**: есть сайт или репозиторий, проект не заброшен.
3. **Описание на русском**, одно предложение, без рекламных слов («лучший», «революционный»).
4. **Добавляй в подходящую таблицу**, соблюдая формат:

   ```
   | [Название](https://ссылка) | Описание | метки |
   ```

5. **Метки:** 🟢 открытый код · 🆓 бесплатный тариф · 🏠 локальные модели · 🔑 свой API-ключ · 🔌 MCP · 🇷🇺 российский. Метку ⭐ ставят только мейнтейнеры.
6. **Один PR — один инструмент** (или одно исправление).

## Сообщить об устаревшей информации

Инструмент переименовали, закрыли или поменяли тариф? Открой [Issue](../../issues/new?template=update.md). Это так же ценно, как новый инструмент.
