# Урок 01. Как выбрать ИИ-инструмент для разработки

[← К оглавлению](../README.md)

## Шаг 1. Определи, где ты работаешь

| Твоя среда | Что смотреть в первую очередь |
|---|---|
| VS Code | Cursor или Windsurf (форки VS Code), GitHub Copilot, Cline, Continue, Kilo Code |
| JetBrains (IntelliJ, PyCharm, WebStorm…) | JetBrains AI, GitHub Copilot, Sweep, Continue |
| Vim / Neovim / Emacs | Агенты в терминале (Claude Code, Codex CLI, Aider, Gemini CLI), Copilot для Vim |
| Терминал и SSH-серверы | Claude Code, Codex CLI, Gemini CLI, Aider, Goose, pi |
| Браузер, нет локальной среды | Replit, Bolt.new, Lovable, v0, Codex в ChatGPT, Jules |
| Xcode / Android Studio | Встроенные ассистенты IDE + агент в терминале рядом |

## Шаг 2. Реши вопрос приватности

| Уровень | Подход | Инструменты |
|---|---|---|
| Код можно отправлять в облако | Любые коммерческие сервисы | Cursor, Copilot, Claude Code, Codex |
| Можно в облако, но без обучения на данных | Корпоративные тарифы, zero data retention | Enterprise-тарифы крупных сервисов |
| Только свой контур | Self-hosted + модели в своём облаке/сервере | Tabby, OpenHands, Continue/Cline + vLLM |
| Ничего не покидает ноутбук | Локальные модели | Aider/Cline/Continue/Codex CLI + Ollama |

## Шаг 3. Подбери по типу задач

| Задача | Лучший тип инструмента |
|---|---|
| Писать код быстрее в течение дня | Автодополнение + чат в IDE |
| Реализовать фичу или исправить баг «под ключ» | Агент в IDE или терминале |
| Разобраться в чужом большом проекте | Инструменты понимания кодовой базы (Cody, Unblocked), агент в режиме «только чтение» |
| Разгрести бэклог мелких тикетов | Облачные агенты (Jules, Codex, Devin, Factory) |
| Собрать прототип за вечер | Конструкторы (Bolt, Lovable, v0) |
| Повысить качество ревью | Боты для PR (CodeRabbit, Qodo PR Agent, Greptile) |
| Покрыть код тестами | Qodo, Diffblue (Java), Checksum, Meticulous |
| Запускать много задач параллельно | Оркестраторы (Conductor, Vibe Kanban, Superset, Parallel Code) |

## Шаг 4. Посчитай бюджет

- **Подписка** — фиксированная цена и лимиты запросов. Удобно для предсказуемого бюджета.
- **Оплата за токены (BYOK)** — платишь провайдеру модели напрямую. Выгодно при нерегулярной нагрузке, но агентские сессии могут стоить дорого.
- **Локально** — бесплатно, но нужно железо: для комфортной работы агента — видеокарта от 16–24 ГБ или Mac с 32+ ГБ памяти.

Для контроля расходов используй трекеры из раздела «[Учёт токенов и расходов](../README.md#-учёт-токенов-и-расходов)».

## Шаг 5. Проведи честный тест

1. Возьми **3 реальные задачи** из своего проекта: простую, среднюю и сложную.
2. Дай каждую 2–3 инструментам с одинаковой формулировкой.
3. Оцени: правильность, сколько правок пришлось делать, время, стоимость, удобство ревью.
4. Перед тестом добавь в репозиторий `AGENTS.md` — без контекста любой агент работает хуже.

## Частые ошибки

| Ошибка | Как правильно |
|---|---|
| Давать агенту размытую задачу «сделай красиво» | Описывать цель, ограничения и критерий готовности |
| Принимать изменения без ревью | Всегда смотреть дифф и запускать тесты |
| Держать один гигантский чат | Новая задача — новая сессия; длинный контекст ухудшает качество |
| Не настраивать правила проекта | Написать `AGENTS.md` с командами и соглашениями |
| Давать полный доступ на рабочей машине | Песочницы, worktree, allow-list команд |
