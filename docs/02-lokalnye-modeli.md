# Урок 02. Бесплатно и приватно: локальные модели в VS Code и терминале

[← К оглавлению](../README.md)

Связка «open-source агент + локальная модель» даёт ИИ-помощника, который работает без интернета, бесплатно и не отправляет код наружу.

## 1. Установи Ollama

| ОС | Команда |
|---|---|
| Windows / macOS | Скачай установщик с [ollama.com/download](https://ollama.com/download) |
| Linux | `curl -fsSL https://ollama.com/install.sh \| sh` |

Проверь: `ollama --version`.

## 2. Выбери модель под железо

Названия и размеры моделей обновляются часто — смотри актуальный список в [библиотеке Ollama](https://ollama.com/library) (поиск по слову `coder`).

| Память видеокарты / Mac | Ориентир | Для чего |
|---|---|---|
| 4–8 ГБ | модели 1.5–7B | Автодополнение |
| 12–16 ГБ | модели ~14B | Чат, простые агентские задачи |
| 24 ГБ | модели ~30B (в т. ч. MoE) | Агент в IDE и терминале |
| 64+ ГБ (Mac, несколько GPU) | 70B и крупные MoE | Близко к облачным моделям |

```bash
ollama pull qwen2.5-coder:7b      # пример модели для автодополнения
ollama pull qwen2.5-coder:14b     # пример модели для чата и агента
```

💡 Агентам нужен большой контекст. Увеличь его: переменная окружения `OLLAMA_CONTEXT_LENGTH=32768`. Подробно о настройке Ollama и llama.cpp — в [deepseek-local-guide-ru](https://github.com/justxor/deepseek-local-guide-ru).

## 3. Подключи к редактору

### Continue (VS Code / JetBrains)

1. Установи расширение Continue.
2. Открой настройки Continue → **Add model** → провайдер **Ollama** → выбери модель.
3. Для автодополнения укажи отдельную маленькую модель — так подсказки будут быстрыми.

### Cline / Kilo Code (VS Code)

1. Установи расширение.
2. В настройках: **API Provider → Ollama**, Base URL `http://localhost:11434`, выбери модель.
3. Включи подтверждение команд и правок вручную, пока не привыкнешь к поведению агента.

### Zed

В настройках Zed (`settings.json`) добавь провайдер `ollama` — модели появятся в панели ассистента.

## 4. Агент в терминале

```bash
# Aider
pip install aider-chat
aider --model ollama_chat/qwen2.5-coder:14b

# Codex CLI с локальной моделью
codex --oss

# Goose: при первом запуске выбери провайдера Ollama
goose configure
```

## 5. Любой OpenAI-совместимый сервер

Почти все инструменты принимают «OpenAI-compatible» эндпоинт. Значит, вместо Ollama можно использовать LM Studio (`http://localhost:1234/v1`), llama.cpp-сервер (`http://localhost:8080/v1`), vLLM (`http://localhost:8000/v1`) — например, на мощном сервере в локальной сети для всей команды.

## Ограничения локальных моделей

| Ограничение | Что делать |
|---|---|
| Слабее облачных флагманов на сложных задачах | Разбивай задачу на шаги, давай больше контекста |
| Медленнее на слабом железе | Модель поменьше для автодополнения, побольше — для чата |
| Хуже вызывают инструменты (tool calling) | Выбирай модели, явно обученные для агентов и кода |
| Маленький контекст по умолчанию | Увеличь `num_ctx` / `OLLAMA_CONTEXT_LENGTH` |

Гибридный вариант: локальная модель для автодополнения и рутинных вопросов, облачная (по своему ключу) — для сложных агентских задач.
